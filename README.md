# Currency Converter

A responsive web-based currency converter built using HTML, CSS, and JavaScript. It fetches exchange rates from a public API and allows users to convert amounts between different currencies.

## Features

* Convert amounts between supported currencies.
* Fetch exchange rates using the Fetch API.
* Currency selection through dropdown menus.
* Country flags update based on the selected currency.
* Input validation to prevent invalid amounts.
* Error handling when exchange rates cannot be fetched.
* Responsive layout for different screen sizes.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Fetch API
* Async/Await
* Exchange Rate API

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Select the currencies, enter an amount, and click the button to convert.

## API

Exchange rates are retrieved from the [Fawaz Ahmed Currency API](https://github.com/fawazahmed0/currency-api).
